# documentar-funcionalidade

> Rascunho inicial. Refinar por PR.

- Use o template `docs/funcionalidades/_templates/docs.md`.
- Escreva para o profissional (tatuador, trancista, manicure), não para desenvolvedor.
- Frases curtas, passos numerados, vocabulário do glossário.
- Diga quem pode usar (papel) e em qual plano.
- Atualize o changelog e o status no backlog.
