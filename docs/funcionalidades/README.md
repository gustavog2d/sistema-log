# Funcionalidades

Uma pasta por funcionalidade: `<ID>-<slug>/` (ex.: `PLT-003-cadastro-self-service/`). Para começar, copie os arquivos de [_templates/](_templates/).

| Arquivo | Quem escreve | Quando |
| --- | --- | --- |
| `spec.md` | Agente Produto (+ Arquiteto na seção de API e dados) | Antes de tudo |
| `openapi.yaml` | Agente Arquiteto | Junto com a spec |
| `test-plan.md` | Agente QA | Depois dos critérios de aceite, antes do código |
| `docs.md` | Agente Documentação | Antes do merge |

O backlog atual está em [../13-backlog.md](../13-backlog.md). Nenhuma pasta de funcionalidade foi criada ainda.
